# LICENSES — AutoOntologyBench 20K public test release

This directory records every third-party source license and attribution
obligation for the 20K benchmark, with verbatim copies of the pinned
license/notice texts where they exist.

- `ATTRIBUTION.md` — master table (source, lane, license, decision, obligation).
- `<source_id>/SUMMARY.md` — per-source decision, pinned snapshot, obligation.
- `<source_id>/LICENSE*`, `NOTICE*`, `REQUIRED.ATTRIBUTION`, `README` —
  verbatim (sanitized) copies of the pinned license evidence.

No raw database content is duplicated here. Raw databases (ChEMBL 37 SQLite,
UniProt Swiss-Prot, Reactome release-98, Rhea/ChEBI, pinned source snapshots)
are bundled separately under `release_20k/source_data/` per PI confirmation of
academic permission; consult that directory's own manifest for its checksums.
